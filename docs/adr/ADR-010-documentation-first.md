# ADR-010 — Documentation-first

## Status

Accepted

## Contexto

O projeto será desenvolvido com assistência de IA e poderá evoluir para um produto comercial. Precisamos de uma base comum antes do primeiro código.

## Decisão

A documentação de produto, arquitetura, contexto de IA e ADRs será o primeiro estado versionado do repositório. O código de aplicação só começa depois desse baseline documental.

## Motivos

- estabelecer uma fonte de verdade;
- preservar decisões;
- reduzir ambiguidades para a IA;
- permitir histórico claro desde o primeiro commit.

## Consequências

O primeiro commit será documental.
