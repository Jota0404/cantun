# ADR-011 — Nome atual do projeto: CANTUM

## Status

Accepted

## Contexto

`Salmodia` era o nome provisório utilizado durante o desenvolvimento do MVP.

O MVP foi concluído e validado, e o nome atual do projeto/aplicativo passa a ser `CANTUM`.

Esta decisão é apenas de nomenclatura do projeto neste momento. Não representa lançamento comercial, registro de marca, domínio, posicionamento comercial, redesign ou nova identidade visual.

## Decisão

O nome exibido e utilizado para identificar o aplicativo é:

**CANTUM**

## Escopo da alteração

Devem utilizar `CANTUM`:

- nome visível do aplicativo;
- título da aplicação;
- nome e short name do manifest PWA;
- documentação que descreva o nome atual do projeto;
- textos de interface relacionados ao nome do aplicativo.

Devem permanecer inalterados, salvo necessidade futura explícita:

- nomes históricos de arquivos documentais, incluindo `SALMODIA_PRODUCT.md` e `SALMODIA_ARCHITECTURE.md`;
- caminhos técnicos;
- nomes de banco e tabelas;
- chaves de storage;
- IDs e UUIDs;
- URLs e referências Git históricas.

## Consequências

A alteração não modifica arquitetura, persistência, modelo de dados, UX ou escopo funcional do MVP.
